Support

AwardGrid for iPhone

Write to %AWARDGRID_SUPPORT_EMAIL%. Say what you tapped, what you expected and what happened. Never send an API key: the app shows only a key's last four characters, and that is all anyone helping you needs.

What it needs

  • An iPhone with iOS 18 or later.
  • Optional: your own seats.aero account with API access (part of seats.aero Pro, which AwardGrid does not sell), and its API key from the API tab of your seats.aero settings. Without it, AwardGrid shows sample data only.

Common questions

Do I need a seats.aero account?

No. Without one, AwardGrid shows sample data only: search, the List, Calendar and Matrix views, option details, compare, Saved and Watches all work on sample data made on your iPhone, labelled as sample data, and nothing is sent. If you have a seats.aero account with API access, you can connect it in Settings to see results from that account instead.

Where do I find my seats.aero API key?

In the API tab of your seats.aero settings, if your seats.aero account has API access (part of seats.aero Pro, which AwardGrid does not sell).

My seats.aero settings show no API tab. Will AwardGrid work?

Only on sample data. seats.aero says not every Pro account or country gets API access; without a key, AwardGrid shows sample data only. AwardGrid depends on seats.aero's Partner API, which seats.aero licenses for non-commercial use and can limit or withdraw.

Why does a search use seats.aero calls?

Each search on your seats.aero account goes to seats.aero with your key, and seats.aero counts the calls against a daily limit. The app stops at 950 of seats.aero's 1,000 daily calls and keeps results on the device for 45 minutes, so repeating a search costs no calls. The app's own count restarts at midnight UTC, when seats.aero resets usage. Sample data uses no seats.aero calls.

What does "not monitored" mean?

seats.aero does not track that route for the programs you asked about, so no result there is not the same as no seats. A route whose list could not be loaded says so instead.

When are watches checked?

When you open the app or come back to it, and at no other time. iOS cannot promise to run an app while you are not using it, so AwardGrid does not claim to.

Are the results live?

They are seats.aero's cached availability, with how old each result is. Awards disappear; confirm on the program's own site before you transfer any points.

How do I remove my key or my data?

Remove your seats.aero key in Settings and clear cached results there. Exit sample data to delete everything sample data kept. The privacy policy lists everything the app keeps and sends.

常见问题

需要 seats.aero 账户吗？

不需要。不连接 seats.aero 账户时，AwardGrid 只显示示例数据：查票、列表、日历和矩阵视图、选项详情、比较、收藏和关注都可以使用本机生成的示例数据，并标注为示例数据，不会发送任何内容。如果你有带 API 权限的 seats.aero 账户，可以在设置中连接它，看到该账户的结果。

在哪里找到 seats.aero API 密钥？

在 seats.aero 设置的 API 页里，前提是你的 seats.aero 账户有 API 权限（属于 seats.aero Pro，AwardGrid 不出售）。

我的 seats.aero 设置里没有 API 页，AwardGrid 还能用吗？

只能用示例数据。seats.aero 说明，并非每个 Pro 账户、每个国家或地区都能获得 API 权限；没有密钥，AwardGrid 只显示示例数据。AwardGrid 依赖 seats.aero 的 Partner API，seats.aero 只许可非商业用途，并且可以限制或收回。

为什么查票会消耗 seats.aero 调用？

用你的 seats.aero 账户查票时，每次查票都会携带你的密钥发往 seats.aero，seats.aero 按每日上限计数。seats.aero 每天允许 1,000 次调用，应用在 950 次时停止；结果在本机保留 45 分钟，重复查询不消耗调用。应用自己的计数在 UTC 午夜重新开始，seats.aero 也在这时重置用量。示例数据不消耗 seats.aero 调用。

“未监测”是什么意思？

seats.aero 没有为你所查的里程计划跟踪这条航线，所以那里没有结果不等于没有座位。航线列表无法加载时，应用会如实说明。

关注什么时候检查？

在你打开或回到应用时检查，其他时间不会。iOS 无法保证应用在你没有打开它时运行，所以 AwardGrid 不作这样的承诺。

结果是实时的吗？

结果是 seats.aero 的缓存数据，并注明每条结果的数据时间。里程票随时会消失；转点前请先在里程计划官网确认。

如何移除密钥或数据？

在设置中移除 seats.aero 密钥、清除缓存结果。退出示例数据即可删除示例数据保存的全部内容。隐私政策列出了应用保存和发送的全部内容。
