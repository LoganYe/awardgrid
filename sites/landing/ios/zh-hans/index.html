iPhone 里程票查询

一张表，用你自己的密钥

用中文或英文输入航线和日期，也可以在编辑器里逐项设置。AwardGrid 把 seats.aero 缓存的里程票数据排进一张表，可以同时包含多个出发地、多个目的地，日期范围最长 92 天。每一格为你所查的每个舱位分别列出最低里程，并注明所属里程计划和剩余座位；税费和数据时间显示在每个选项里。

使用前提

  • 运行 iOS 18 或更高版本的 iPhone。
  • 你自己的 seats.aero 账户，要有 API 权限（属于 seats.aero Pro，AwardGrid 不出售）；API 密钥在 seats.aero 设置的 API 页里。没有这个密钥，App 什么也搜不到。
  • AI 辅助（Ask）是可选功能，需要你自己的 Anthropic API 密钥。每次提问由 Anthropic 按此密钥计费。
  • AwardGrid 依赖 seats.aero 的 Partner API，seats.aero 只许可非商业用途，并且可以限制或收回。

常见问题

AwardGrid 免费吗？

AwardGrid iPhone 版已提交 App Store，定价为免费，没有内购。你自己的 seats.aero 数据（可选）：如果你的 seats.aero 账户有 API 权限（属于 seats.aero Pro，AwardGrid 不出售），你可以连接这个账户，看到它的结果，而不是示例数据。

AwardGrid 和 seats.aero 有关联吗？

没有。AwardGrid 与 seats.aero、Anthropic、任何航空公司或任何里程计划均无关联，也未获其认可或赞助。它的数据来自 seats.aero。

有新的里程票放出时，AwardGrid 会提醒我吗？

不会。你关注的查询只在你打开或回到 App 时检查，其他时间都不检查；没有后台检查，也没有通知。

数据是实时的吗？

不是。结果来自 seats.aero 的缓存，并非实时查询；每条结果都标明了数据时间。转点之前，请先到该里程计划的官网确认。

支持哪些里程计划？

seats.aero 列出的 26 个里程计划，前提是 seats.aero 监测这条航线；它没有监测的航线会标为“未监测”。

需要 AI 密钥吗？

只有 AI 辅助（Ask）需要，它是可选功能。查票只需要你的 seats.aero 密钥。

可以用中文查询吗？

可以。航线和日期可以用中文或英文输入，也可以在编辑器里逐项设置。App 的界面是英文或简体中文。

AwardGrid 能订票吗？

不能。某个选项有 seats.aero 提供的跳转链接时，App 会打开这个链接；没有时，你可以复制查询条件。App 从不订票。

支持往返吗？

不支持。只能查单程，不能查往返或多段行程，也不能设置乘客人数。

AwardGrid 以后会不会用不了？

AwardGrid 依赖 seats.aero 的 Partner API，seats.aero 只许可非商业用途，并且可以限制或收回。

哪里能下载？

AwardGrid iPhone 版已提交 App Store，目前还不能在那里下载。它将在 174 个国家或地区提供，中国大陆除外。
