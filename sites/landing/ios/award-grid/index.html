How the table works

See award seats for several origins, destinations and dates in one table

AwardGrid is an iPhone app by Curastone CORP. It puts seats.aero's cached award availability for several origins, several destinations and up to 92 days into one table. It needs your own paid seats.aero Pro subscription with API access; without that key it searches nothing.

How it works

  1. Add your seats.aero Pro API key, from the API tab of your seats.aero settings. Keys stay in your iPhone's Keychain, with iCloud Keychain sync off.
  2. Type the routes and dates in English or Chinese, or set them in the editor. Programs, nonstop only and a mileage cap are optional filters; a search asks for business and first unless you choose other cabins.
  3. Read the result as a List, a Calendar or a Matrix; compare up to four options and save results on the device.
  4. For an option, AwardGrid opens seats.aero's booking link when there is one; otherwise you copy the search. It never books. Confirm on the program's own site before you transfer points.

What the table shows

In the Matrix, rows are the dates and columns the routes. Each cell shows the lowest miles for each cabin you asked for, with the program and the seats left. Miles in different programs are not equivalent.

Each option's card shows the route, the date, the cabin, the miles, the fees, the program, the seats left and how old the data is. Where seats.aero does not give the fees, the card says "Fees not yet confirmed"; where it does not give a seat count, "Seat count not provided"; where it does not give an update time, "Source update time unknown".

An empty line in a cell says why, such as "No matches" or "Not monitored".

Limits to know first

  • Results are seats.aero's cached availability, not a live search, and each shows how old it is.
  • It covers the 26 programs seats.aero lists, where seats.aero monitors the route; a route it does not monitor is marked "not monitored".
  • Searches are one-way: no round trips, multi-city or passenger count.
  • The app stops at 950 of the 1,000 daily calls a Pro key allows and keeps results on the device for 45 minutes, so repeating a search costs no calls.
  • Watches are checked when you open or return to the app, and at no other time; there is no background check and no notification.
  • iPhone only, iOS 18 or later.
  • AwardGrid depends on seats.aero's Partner API, which seats.aero licenses for non-commercial use and can limit or withdraw. Check your seats.aero settings show an API tab before you subscribe.

When something else suits you better

AwardGrid has no live search, no round trips and no alerts or notifications. If you need any of these, a tool built for them will suit you better.
